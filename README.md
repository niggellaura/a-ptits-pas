# À p'tits pas — site statique

Version autonome pour **GitHub Pages**.

## Le site ne dépend d'aucun hébergeur applicatif

Le site est constitué uniquement de fichiers HTML, CSS, SVG et PNG.
Il n'utilise **ni Netlify, ni Vercel, ni Firebase, ni Formspree, ni CDN, ni script externe**.

Tu peux donc déposer directement le contenu du dossier dans un dépôt GitHub et activer GitHub Pages.

### Ce qui reste volontairement externe

- **HelloAsso** : uniquement pour le paiement des dons, via un lien externe.
- **Instagram / Facebook** : uniquement comme liens vers les réseaux sociaux.
- **E-mail** : le formulaire de contact ouvre le logiciel de messagerie de la personne avec l'adresse de l'association.

## Structure

- Accueil
- Notre mission
- Nos actions
- Actualités
- Histoires de bébés
- Notre équipe
- Ateliers de portage
- Contact
- Faire un don
- Pages projets individuelles

## À compléter avant publication

- Ajouter les photos/noms validés de l'équipe.
- Ajouter les vraies histoires de bébés après accord des familles.
- Remplacer les illustrations provisoires des projets lorsque les vraies photos seront disponibles.
- Remplacer le lien HelloAsso par l'URL exacte de la page de don de l'association.
- Renseigner les vrais identifiants Instagram/Facebook si nécessaire.
